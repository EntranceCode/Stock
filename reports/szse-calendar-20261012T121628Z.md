# 深交所独立交易日历建立与验证

时间：2026-10-12 UTC。目标：补齐 `sse_calendar` 数据集长期列出的缺口 `SZSE_calendar_independent_validation`。

## 来源与归档

目录：`config/exchange-calendar-sources-szse.json`。含 2018–2026 共 9 份年度《部分节假日休市安排》通知，以及 2 份调整通知：

| 年份 | 类型 | 公告日 | 文号 |
|---|---|---|---|
| 2018–2023 | 年度 | 2017-12-22 起逐年 | 无 |
| 2024 | 年度 | 2023-12-26 | 深证会〔2023〕409号 |
| 2025 | 年度 | 2024-12-23 | 深证会〔2024〕413号 |
| 2026 | 年度 | 2025-12-22 | 深证会〔2025〕481号 |
| 2019 | 调整（劳动节） | 2019-04-18 | 无 |
| 2020 | 调整（春节延长） | 2020-01-27 | 无 |

全部取自深交所官网（`www.szse.cn`、`investor.szse.cn`），逐份实际请求核实。归档运行：`data/external/calendar_sources_szse/20261012T121609Z_d5c1b8b6`，11 份原始 HTML 各含 SHA-256。

判别依据：正文同时包含该年份、"休市"与"深圳证券交易所"，与 SSE 用"上海证券交易所"对称。**不使用文号作为条件**，因为 2020 年及 2018–2023 年通知没有深证会文号，只有 2024 年以后才有。

未采用：深交所站内搜索 API 返回 500；`big5.szse.cn` 繁体页面未使用。2026 年起深交所另发逐节日通知（清明、劳动节），日期与年度通知一致，不构成调整，未纳入目录。

## 目录生成方式

新增 `scripts/extract_calendar_notice.py`：从归档通知正文抽取休市区间——先经 BeautifulSoup 去标签，再去除全部空白（通知 HTML 会把"2024"切成"202 4"，直接解析会漏日期），然后按节日条目取第一个"休市"之前的日期或区间。9 份通知共 59 个区间均由该脚本生成后逐条与原文核对，避免手工转录。

## 构建

`scripts/fetch_calendar_sources.py` 与 `scripts/build_exchange_calendar.py` 已泛化为按 catalog 的 `exchange` 驱动。**SSE 行为与输出路径保持不变**，并用既有归档快照做回归构建验证：`rows 3207`、`open 2126`、5 只上交所 ETF 零差异、`exact True`。

构建过程中修掉两处原先隐含的 SSE 假设：构建脚本把 `exchange` 硬编码为 `"SSE"`，且调用 `is_scheduled_open()` 时未传 exchange（默认 SSE），SZSE 下会直接抛 `ExchangeCalendar/date outside verified source scope`。清单字段改为中性的 `all_observation_comparisons_exact`，SSE 保留旧名以兼容 `scripts/data_status.py`。

构建结果：`data/external/calendar_szse/20261012T121628Z_5c189baf`，3,207 个自然日、2,126 个计划开市日。

## 验证

1. **与实际成交观测**：sz159915 的 2,122 个交易日中，**0 天落在计划休市日**。唯一一天计划开市而无 bar 是 2021-02-08；经核对，同日 000001（平安银行，深市）正常成交，说明该日确实开市，缺 bar 属 sz159915 这一序列自身的数据缺口，不是日历错误。
2. **与上交所日历逐日对比**：2018-01-01 至 2026-10-09 共 3,204 个重叠日，两者开市/休市判定**零分歧**。
3. **目录层面**：9 个年份的休市区间与上交所目录**逐年完全一致**（该等价性已由 `tests/test_exchange_calendar.py` 固化）。

## 仍未解决

- **未登记**：SZSE 日历尚未写入 `config/datasets.json`，因此 `status`/`check-data` 仍只列 6 个数据集。`sse_calendar` 的 manifest 是冻结的历史产物，其中那条 SZSE 缺口未回写。
- **证券级状态**：日历只表达"交易所计划是否开市"，不代表任何个别证券可成交；`security_level_status` 仍是缺口。
- **范围边界**：scope 止于 2026-12-31，且未包含 2027 年元旦通知。若 2026-12-31 落入 2027 年元旦休市，两个日历都会把它当作开市日。这与既有 SSE 日历受同一限制。
