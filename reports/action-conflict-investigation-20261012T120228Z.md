四个公告均载明"差异化分红送转：是"。600025 的两笔分别给出了三类股东各自的实际分红金额，并单列"每股平均分红计算公式"作为除息参考价减项；600989 的两笔给出限售股与流通股两个金额，除息减项为 0.28 元。

## 统一结论

**5 条冲突没有一条是数据错误。**两处来源字段描述的是不同股东类别的真实现金，而除息参考价参数又是第三个数值：

- `PRETAX_BONUS_RMB`（每 10 股）对应社会公众股/流通股的实际现金；
- `IMPL_PLAN_PROFILE` 中"派 N 元"的 N 对应原大股东/限售股的实际现金；
- 除息参考价减项是公告按总股本折算的平均分配额，既不是前者也不是后者。

因此现有 `scripts/normalize_action_samples.py:stock_event_values` 把前两者当作同一现金口径交叉校验，在这类事件上必然报 `Cash field disagrees with implementation description`。报错是校验假设不成立的结果，不是源数据有误。

## 仍未核实的部分

1. **日期表缺项**：600025 / 2020-06-19 与 600989 / 2019-09-27 的除权息日期表在中国证券报电子报 HTML 中是图片，正文以占位符呈现，登记日/除权息日/发放日均未从文本核实，这两笔的支付日保持未知。
2. **公告内部算术不一致**：600025 / 2020-06-19 公告表述"公司股本总数为 18,000,000,000 股，共分配现金股利 2,740,000,000.00 元，对应每股现金红利 0.15 元"，但按其自述总额与总股本换算为 0.15222 元。按本项目规则不以换算值替代公告原文，该参数保留为待核，且不得用第一轮预案中的 0.15222 顶替。
3. **报纸版原件不可读**：600989 / 2020-06-04 的报纸版 PDF 为图像编码，抽取文本为乱码，仅作原始图片留存；该事件数值由文本版 PDF 与中国证券报电子报两处独立来源交叉核实，两者完全一致。

## 数据模型要求（本轮未实施）

缺口不是"让报错消失"，而是把三个现金口径分开保存。建议在事件记录中显式区分：

| 字段语义 | 用途 |
|---|---|
| 普通账户每股现金（社会公众股/流通股） | 账户现金到账与总收益计算 |
| 特殊股东每股现金（原大股东/限售股） | 保留来源事实，不并入普通账户现金流 |
| 除息参考价减项（平均分配额） | 仅用于复权与除息参考价，不代表任何账户到账金额 |
| 差异化分红标记及其证据引用 | 说明三者的来源与适用股份类别 |

本轮不实施该改动：其一，两笔事件的日期表尚未核实；其二，除息参数存在公告内部不一致。在这些项解决前，按本项目既有规则，5 条记录继续保留隔离，且不以"金额较小""接近加权平均""另一年份公式"等理由推断解除。
