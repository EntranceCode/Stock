# 混合策略量化投资系统

当前版本：v0.2.2，独立系统核心、本地研究工作台与真实数据准备。项目位于`D:\vscode\Stock`，系统Python包为`hybrid_quant`；适用范围是A股个股和场内ETF，日线决策，只做多、不使用杠杆。

用户确定的方向：个股选股 + ETF轮动；最大回撤研究目标为15%–20%。该目标不是收益或风险承诺。

**实施路线以[实施设计](docs/implementation-design.md)为准。** 该文档按依赖顺序重排了从零到可运行的路径：阶段 0 是字段供给矩阵与六项待决决策（D1–D6），其后才是数据契约、采集归档、可判定的数据集判据、引擎边界、验收与终止线。在 D1、D2、D4 确定之前，采集与实现都可能白做，因此当前工作暂停在阶段 0。

已实现个股多因子、ETF轮动、防御模块、组合风控、次日订单模拟与现金持仓账本，并提供合成数据演示。新增本地工作台，可查看数据覆盖、查询股票与ETF日线、浏览只读策略配置、运行工程演示和分页检查订单/成交/决策记录。运行时无AlphaMaster依赖；原有行情只作为待核验数据来源。实现范围及后续开发见 [开发状态](docs/development-status.md)，研究规则见 [混合策略系统设计](docs/hybrid-system-design.md)。权重和参数仍是待验证假设，尚未进行真实历史策略回测或连接券商。

在本目录运行：

```powershell
python -B -m hybrid_quant serve --port 8765
python -B -m hybrid_quant demo
python -B -m hybrid_quant status
python -B -m hybrid_quant check-data
python -B scripts/run_tests.py
```

启动`serve`后打开 [本地研究工作台](http://127.0.0.1:8765)。服务仅监听本机地址；在运行服务的终端按`Ctrl+C`停止。当前已安装的解释器也可使用`D:\miniconda3\python.exe`。核心和合成演示使用Python标准库；真实行情预览另需`pyarrow`，本项目已在`.deps/parquet`保存本地依赖。

## 从仓库克隆后

```powershell
git clone git@github.com:EntranceCode/Stock.git
```

仓库只包含代码、配置、文档与核验报告。真实数据目录`data/`（约27 GB，37,000 余个文件，含不可再取的公告与 PDF 归档）和本地依赖`.deps/`（约87 MB）按`.gitignore`排除，不在版本库内，需要单独取得或重新采集。

| 用途 | 需要的依赖 |
|---|---|
| `hybrid_quant`核心、`demo`、`status`、`check-data` | 仅Python 3.11+标准库 |
| `serve`工作台启动与页面浏览 | 仅标准库（日线预览接口另需`pyarrow`） |
| `scripts/`中读写Parquet的脚本 | `pyarrow`，部分还需`pandas` |
| `scripts/fetch_baostock_history.py`采集 | `baostock` 0.9.4 与 `pyarrow` |
| 完整测试套件 | `pyarrow` 与 `pandas` |

相关脚本会先把项目内的`.deps/parquet`与`.deps/baostock`加入模块搜索路径，因此恢复可选依赖有两种等价方式：

```powershell
pip install pyarrow pandas baostock
# 或把依赖放回项目内的 .deps/parquet 与 .deps/baostock
```

缺少`pyarrow`时`scripts/run_tests.py`仍会运行并返回0：需要Parquet的81项检查以明确的跳过原因记录，其余检查照常执行（在当前完整环境中为212项全部通过、无跳过）。

真实数据集不随仓库分发，因此克隆后`status`会把注册表中每个数据集报告为`manifest_missing`，`check-data`返回退出码2，日线预览返回依赖或证据不可用的明确错误。这不是故障，而是准入门的正常行为：在缺口解决前，真实历史数据始终保持`backtest_ready=false`，不会被当作可回测输入。

`demo`使用合成证券、行情、财务与日期验证完整程序链路，结果保存在唯一的`reports/demo/<运行ID>`目录，不能用来证明投资收益。`check-data`在真实历史证据尚不完整时返回退出码2；没有强制跳过准入的开关。

行情预览先核验归档文件哈希，再读取单只证券日线；复权、成交额、字段可用时间与交易状态未知时保持为空。预览接口不生成策略信号，合格历史输入的独立契约见 [快照接口说明](docs/snapshot-bundle-contract.md)。本轮182项自动检查通过；工作台浏览器验证在v0.2.0完成，见 [工作台验证记录](reports/dashboard-validation/validation.md)。

运行性能：回测的已知历史查询按快照记忆化（剖析显示其占回测耗时84%），合成快照只保留最近260个交易日窗口（引擎最大回看121个交易日，演示输出与此前逐字节一致）；工作台概览缓存15秒、数据准入校验缓存60秒——准入校验会对全部已注册文件做全量SHA-256，数据就绪后每次请求需约33秒，缓存后每个窗口只校验一次。实测200只证券×2,400个交易日回测从161秒降到45秒。服务读请求30秒超时、accept backlog为32，响应头不暴露解释器版本；`.deps`本地依赖追加在导入路径末位而非首位，已安装包优先，防止vendored副本劫持同名模块。

已检查用户提供的本地行情数据，见 [数据检查与接入评估](docs/local-data-assessment.md)。股票日线可作为候选数据，但时间编码、复权和成交量单位需核验；指数异常、分钟线精度损失及财务/ETF数据缺口尚待解决。只读检查脚本见 `scripts/inspect_market_data.py`，详细结果保存在 `reports/local-data-audit/`。
